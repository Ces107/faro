# Plantilla de factura (modelo)

Modelo de factura para cobrar el pack. Rellena tus datos fiscales (entre corchetes). Antes de emitir facturas de verdad tienes que estar dado de alta como autónomo; consúltalo con tu asesor.

---

```
FACTURA  Nº [2026-001]
Fecha: [DD/MM/AAAA]

EMISOR
[Nombre y apellidos]
NIF: [NIF]
[Dirección]
[Email / teléfono]

CLIENTE
[Nombre del negocio]
NIF/CIF: [NIF del cliente]
[Dirección]

------------------------------------------------------------
Concepto                                        Importe
------------------------------------------------------------
Pack de presencia digital (web + ficha Google
 + WhatsApp + tarjeta de reseñas)               [350,00] €
------------------------------------------------------------
Base imponible                                  [350,00] €
IVA (21%)                                         [73,50] €
[Retención IRPF si aplica (-15%)]               [-52,50] €
------------------------------------------------------------
TOTAL A PAGAR                                   [371,00] €
------------------------------------------------------------

Forma de pago: [Bizum / transferencia a IBAN ...]
```

## Notas

- **IVA 21%**: el servicio lleva IVA general. Lo repercutes al cliente y lo ingresas en tu declaración trimestral.
- **Retención IRPF**: si facturas a una empresa o autónomo, puede aplicarse retención de IRPF (7% nuevos autónomos los primeros años, 15% después). Si el cliente es un particular, no se aplica retención. Confírmalo con tu asesor.
- **Numeración**: las facturas van numeradas y correlativas.
- **Conserva** copia de cada factura. Hoy hay herramientas gratuitas para emitirlas; pídele a tu asesor la que use.
